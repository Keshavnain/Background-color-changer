# 🎨 Background Color Changer

A simple and interactive background color changer built using HTML, CSS and JavaScript.

The project allows users to change the background color of a webpage through a button click.

## 🚀 Features

- 🎨 Changes background color dynamically
- 🖱️ Button-based user interaction
- ⚡ Instant color change
- 📱 Simple and clean interface

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
